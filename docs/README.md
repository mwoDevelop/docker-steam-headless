# Indeks dokumentacji

Użyj tej strony jako punktu wejścia do dokumentacji repozytorium. To oddziela
aktualne wytyczne operacyjne z historii projektowania i wcześniejsze przewodniki po kontenerach.

## Kontrola maszyn wirtualnych w Google Cloud

- [Cloud Run VM Control](./cloud-run-vm-control.md): architektura, dostęp
model, wdrożenie i interfejs GUI GitHub Pages.
- [Minecraft management](./minecraft-management.md): środowiska wykonawcze serwerów, RCON,
właściwości serwera i zarządzanie treścią Modrinth.
- [Troubleshooting](./troubleshooting.md): zwykła maszyna wirtualna, światło słoneczne, światło księżyca,
diagnostyka sieci i GUI.
- [Legacy GitHub Pages mode](./github-pages-vm-control.md): historyczny
Przepływ tokenu GitHub. Nie używaj go w bieżącym wdrożeniu Cloud Run.

## Operacje i odzyskiwanie

- [Worms W.M.D. Linux launch fix](./worms-wmd-linux-fix.md): specyficzne dla gry

## Plany inżynieryjne i zapisy historyczne
